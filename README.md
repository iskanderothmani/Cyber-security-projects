## Project principles

- Use synthetic or sanitized data only; never commit company logs, personal data, secrets, tokens, or private keys.
- Keep experiments isolated and non-destructive. Test only systems you own or are explicitly authorized to assess.
- Document architecture, prerequisites, setup, tests, limitations, and defensive use cases.
- Prefer reproducible builds, dependency pinning, secure defaults, and automated checks.
- Treat AI-generated security conclusions as recommendations that require validation, not as authoritative incident decisions.
